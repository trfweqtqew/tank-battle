# 钢铁坦克大战 🎮

一个纯 HTML5 Canvas 编写的网页版坦克对战小游戏，单文件、无需任何依赖，打开即可游玩。

## ✨ 玩法特色

- **经典坦克对战**：控制你的坦克，消灭不断来袭的敌军，守住基地核心。
- **可破坏地形**：砖墙能被炮弹摧毁，钢墙不可破坏，利用地形掩护自己。
- **多种关卡**：内置多个关卡，越往后敌军越多、速度越快，无限循环挑战。
- **即时反馈**：得分、生命、关卡、剩余敌军实时显示，含爆炸粒子与音效。
- **多端适配**：桌面用键盘操作，触屏设备自动显示虚拟方向键与开火按钮。

## 🕹️ 操作方式

| 操作 | 键盘 |
| ---- | ---- |
| 移动 | 方向键 / `W` `A` `S` `D` |
| 开火 | `空格` |
| 暂停 / 继续 | `P` |
| 静音 | `M` |

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何环境。

也可以本地起一个静态服务器：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 🧱 技术实现

- 纯原生 JavaScript + HTML5 Canvas，无框架、无依赖。
- `requestAnimationFrame` 游戏循环，网格碰撞检测。
- Web Audio API 实时合成音效。
- 响应式布局 + 触屏虚拟按键。
